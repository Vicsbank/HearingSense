You are an impartial fact-level evaluator of recaps of conversations. The conversations are synthetic. Each
recap was written by an unknown system; you do not know which, and must not guess. Judge only against the
transcript and reference lists given. Do NOT use lexical overlap as a criterion: a recap can reuse the right
words and still state something false (wrong date, swapped person, tentative plan presented as confirmed,
superseded value presented as current, a relationship or reason nobody stated).

Read the batch JSON file given to you. It holds conversations; each has: transcript (numbered lines, no speaker
labels, may have recognition errors), facts (reference facts, id/text/critical), must_not (plausible but UNSUPPORTED
statements), uncertain (matters left unconfirmed in the speech), and summaries S1..Sn. Each summary is split into
numbered UNITS (sentences / bullet points) with ids like a1, a2, k1.

For EVERY summary produce:
1. units: for each unit, count its distinct factual claims (n_claims, at least 1 for a sentence that states anything;
   0 for pure filler such as "The conversation was about..." with no checkable content), how many are NOT supported
   by the transcript (n_unsupported: contradicted, invented, or only inferable by guessing) and how many are
   genuinely ambiguous (n_ambiguous: arguably supported / depends on reading of a garbled passage). A claim that
   is a fair paraphrase or a correct summary of several lines is supported. Stating the superseded value as current,
   or stating a tentative thing as settled, is unsupported. Add a short "note" only for unsupported/ambiguous units.
2. facts: for each reference fact id: status "full" (the summary states it correctly and completely), "partial"
   (some of it / missing a key detail / vague), or "none" (absent or stated wrongly); "by": the unit ids that carry it.
3. must_not: for each must_not id, violated true/false (does the summary state or clearly imply it?).
4. uncertain: for each uncertain id: "preserved" (summary keeps it open/uncertain or doesn't resolve it),
   "overstated" (summary treats it as settled), or "absent" (not mentioned at all).
5. correction: if the transcript contains a correction/update of an earlier statement: "correct" (final value is
   presented as current) or "wrong" (old value presented as current, both presented without resolution, or
   correction missed); else "n/a".
6. quality ratings 1-5: natural (reads like fluent natural writing in its language), readable (clear, well organised,
   useful to a reader who could not hear), repetition (5 = no unnecessary repetition, 1 = very repetitive). Also
   "vague" = number of units that use vague agents like "someone said" where the transcript content makes a clearer
   statement possible without guessing.
7. copying: "verbatim" = true if the summary is mostly word-for-word copies of transcript lines.

Be strict and consistent. Same standard for every summary. Output ONE JSON file written to the path you are given:
